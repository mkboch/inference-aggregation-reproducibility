# Data Availability

Benchmark question text, model weights, generated outputs and experimental result
files are not hosted here. Obtain MedQA, MedMCQA and PubMedQA from their original
sources under their licenses/terms. No author-mediated delivery is promised.
The repository provides code, prompts, parser, revisions, configurations, protocol
documentation and deterministic analysis to rerun the pipeline after obtaining
those dependencies. See [workflow](../REPRODUCE.md).
